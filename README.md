# 📈 Stock Price Prediction using LSTM

This project demonstrates an end-to-end pipeline to predict Apple Inc. (AAPL) stock prices using Long Short-Term Memory (LSTM) neural networks.

## 🔧 Tools & Libraries
- Python
- TensorFlow / Keras
- yFinance
- Scikit-Learn
- Matplotlib

## 📊 Workflow
1. Download historical stock data from Yahoo Finance
2. Preprocess using MinMaxScaler
3. Create sequences for LSTM model
4. Train-test split
5. Build and train LSTM model
6. Predict and visualize stock prices
